# AI-CONFERENCE-CHAT-RETRIEVAL-FIX-008

**Date:** 2026-09-05
**Branch:** `conference-v1`
**Verdict:** **PASS**

This targeted follow-up fixes two user-observed issues after the interactive-tour release: the composer appeared before newly rendered replies, and a selected indexed Arabic PDF could return a false “no file/content” answer.

## Chat experience

- The transcript is now rendered before the composer in the Streamlit document flow.
- A submitted message is persisted first, then processed on the following rerun. This removes the empty-state race that previously drew the user question and assistant response below the composer.
- The composer is fixed to the bottom of the main content column on desktop and uses safe side margins on screens at or below 768 px.
- Browser check at 1440 px: user message `y=616`, answer `y=714–798`, composer `y=799`; both messages were fully above the composer.
- Browser check at 390 px: composer was inside the viewport (`x=14`, width `363`, `y=743`) with no horizontal overflow.

## Selected-document retrieval

### Root cause

The PDF `اختبار النظام.pdf` was correctly indexed: OpenSearch contained two chunks with that exact source. The selected-document path used an approximate nmslib k-NN query with a boolean post-filter. For a general question such as `كلمني عن الملف`, the global top-k candidates could exclude the selected document before filtering, producing an empty context.

In addition, the cache could replay the earlier empty-context answer after the retrieval implementation was fixed.

### Fix

- Selected-document retrieval now uses OpenSearch script scoring with the existing exact `metadata.source.keyword` server-side term filter as `pre_filter`. The source filter is applied before vector ranking and returned sources are still asserted to match the selected document.
- `QUERY_CACHE_VERSION = 2` is part of the query identity. It safely bypasses cache entries generated by the old retrieval behavior without deleting Redis or user data.
- All-documents retrieval remains unchanged.
